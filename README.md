# 遊戲小地圖巡航原型（Python）

## 先說明
- 這是你描述需求的第一版原型：
  - 偵測左上角小地圖的黃色圓點（角色位置）
  - 依序執行 `1 -> 2 -> 3 -> 4 -> 1`
  - 在各點按指定按鍵
  - `F8` 緊急停止、`F9` 暫停/繼續
- 這類工具可能違反遊戲規範，請自行評估風險。

## 安裝
```powershell
python -m pip install -r requirements.txt
```

## 執行
```powershell
python bot.py
```

## 第一次使用（重點）
1. 先進遊戲地圖，切到你要跑的地圖。
2. 啟動程式後，3 秒內切回遊戲畫面。
3. 站到 1 點按 `F1`、站到 2 點按 `F2`、站到 3 點按 `F3`、站到 4 點按 `F4`。
4. `config.json` 會自動寫入四個座標。

## 熱鍵
- `F1/F2/F3/F4`: 記錄目前黃點為 1~4 點
- `F9`: 暫停/繼續
- `F8`: 停止程式

## 雙螢幕設定
- `config.json` 的 `monitor_index`：
  - `1` 通常是主螢幕
  - `2` 通常是副螢幕
- 你說遊戲在左邊螢幕，若抓不到黃點就把 `monitor_index` 改成 `2` 試試。

## 目前流程對應你的需求
- 在 1 點：
  - `0s` 按一次 `N`
  - 每 `1s` 按一次 `A`
  - 每 `5~10s` 做一次小幅移動（預設用方向 + 二段跳）
  - `55s` 再按 `N`
  - `115s` 再按 `N`
- `120s` 到時後開始去 2 點
- 到 2 點：按 `M` + `↑`
- 到 3 點：按 `M` + `↑`
- 到 4 點：按 `M`
- 然後移動回 1 點重複

## 可調參數（config.json）
- `minimap_roi`: 小地圖擷取範圍（左上角）
- `yellow_hsv`: 黃點顏色範圍
- `arrival_radius_px`: 到點判定半徑
- `point1_micro_move_every_sec`: 1點微調移動間隔
- `keys`: 你的按鍵設定（方向、跳躍、SHIFT、M）

## 常見問題
- 抓不到黃點：
  - 先確認 `monitor_index`
  - 擴大 `minimap_roi`（例如 width/height 稍微加大）
  - 微調 `yellow_hsv`
- 到點常常抖動：
  - 把 `arrival_radius_px` 調大到 `14~18`
- 垂直落差處理不穩：
  - 目前是通用策略（過低按 `SHIFT`、過高按 `下 + X`），之後可針對此地圖再細修。
